# Preparar el entorno

Necesitas Python 3.10 o superior y un editor de texto. El docente puede instalarlo previamente en los equipos. No necesitas paquetes de pip ni cuentas de servicios para ejecutar los ejemplos.

En una terminal comprueba:

```bash
python --version
```

En Windows, si `python` no está disponible, prueba `py --version` y usa `py` en lugar de `python`. En otros equipos puede ser `python3`. Si ninguna opción funciona, pide al docente preparar Python antes de continuar.

## Obtener el curso

En GitHub abre Code → Download ZIP y extrae el archivo; o, si Git ya está configurado:

```bash
git clone https://github.com/GajoPrograma/Curso_POO_Media_Tecnica_10_2026.git
cd Curso_POO_Media_Tecnica_10_2026
python modulos/00_pensar_antes_de_programar/ejemplo.py
```

La alternativa SSH es para quien ya tenga sus claves configuradas:

```bash
git clone git@github.com:GajoPrograma/Curso_POO_Media_Tecnica_10_2026.git
```

Guarda tus respuestas en otra carpeta o en tu propia rama antes de actualizar. Para actualizar una copia Git limpia usa `git pull --ff-only`; si Git informa cambios locales, conserva tu trabajo antes de resolverlos. La descarga ZIP no mantiene historial de cambios.

Los comandos del curso se ejecutan desde la carpeta que contiene README.md. El proyecto de inventario guarda un archivo local al elegir Guardar; no lo confundas con una entrega en GitHub.
