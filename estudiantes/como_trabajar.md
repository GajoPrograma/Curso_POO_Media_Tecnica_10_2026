# Cómo trabajar y demostrar aprendizaje

Para cada actividad conserva: interpretación del problema, predicción, solución, tres pruebas y reflexión. Usa las plantillas de la carpeta plantillas. La reflexión debe explicar una decisión o error concreto; “aprendí mucho” no permite comprobar qué aprendiste.

En parejas cambia de rol cada 15–20 minutos. Antes de ejecutar, el observador dice qué espera y por qué. Si el resultado difiere, revisen la primera diferencia en la tabla de seguimiento. No cambien varias cosas a la vez sin una hipótesis.

Para entregar: crea una carpeta con código anónimo asignado por el docente y módulo, por ejemplo E07_M04. Incluye archivos .py y un README con instrucciones y pruebas. El docente define el medio de entrega; no subas datos personales al repositorio público.

La ayuda de un compañero, documentación o IA debe registrarse: qué consultaste, qué aceptaste y cómo lo verificaste. En una sustentación individual tendrás que explicar tu solución y modificar una regla. Usar código que no comprendes deja pendiente el aprendizaje, aunque el programa funcione.
