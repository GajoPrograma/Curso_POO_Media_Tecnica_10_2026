# Glosario con ejemplos

| Concepto | Significado y ejemplo |
|---|---|
| Algoritmo | Pasos finitos y precisos; calcular equipos necesarios |
| Abstracción | Seleccionar lo relevante; libro como código, estado y operaciones |
| Estado | Valores actuales de un objeto; disponible=False |
| Clase | Definición para crear objetos; Libro |
| Instancia | Objeto concreto; ejemplar L1 |
| Identidad | Distingue objetos aunque tengan el mismo título |
| Atributo | Dato asociado al objeto; self.codigo |
| Método | Operación de un objeto; prestar() |
| Encapsulación | Controlar cambios mediante operaciones que respeten reglas |
| Invariante | Regla que permanece verdadera; existencias >= 0 |
| Contrato | Entradas válidas, resultados y errores de una operación |
| Composición de objetos | Construir comportamiento con colaboradores; biblioteca y libros |
| Herencia | Relación entre un tipo base y un subtipo sustituible |
| Polimorfismo | Usar una operación común con implementaciones diferentes |
| Excepción | Señal de una condición que interrumpe el flujo normal |
| Persistencia | Conservar datos después de cerrar el programa |
| Prueba de escritorio | Seguir manualmente cambios y decisiones |
| Regresión | Comportamiento antes correcto que un cambio rompe |
| Refactorización | Reorganizar código conservando comportamiento |
| Cohesión | Grado en que las responsabilidades de un módulo se relacionan |
| Acoplamiento | Dependencia entre partes del sistema |
