# Comprobación individual

Duración: 15–25 minutos. Puede hacerse con papel. No consultar el solucionario durante el primer intento.

1. **Predicción (2 puntos).** Predice la disponibilidad de a y b después de a.prestar(). Luego imagina c = a: ¿qué observa c?
2. **Explicación (2 puntos).** Explica con un caso concreto este error: Olvidar self crea una variable local que no actualiza el objeto.
3. **Aplicación (4 puntos).** Crea tres instancias; presta una y demuestra que las demás conservan su estado. Explica qué pasaría si escribieras b = a.
4. **Transferencia (2 puntos).** Propón un cambio de regla de esta situación y explica qué parte del modelo o programa habría que modificar.

Para la predicción y explicación: 0 sin evidencia; 1 parcialmente correcta; 2 correcta y justificada. Para aplicación: 0 sin propuesta; 1 idea sin completar; 2 resuelve caso normal; 3 incluye límite; 4 incluye inválido y justifica. Transferencia: 0 sin relación; 1 cambio pertinente sin impacto preciso; 2 cambio e impacto correctos.

**Criterio de avance sugerido:** 7/10 y evidencia de comprensión del criterio: Explica self usando una instancia concreta y demuestra independencia entre objetos. No constituye una escala institucional oficial. Si hace falta apoyo, realiza una simulación pequeña y una nueva comprobación con datos diferentes.
